# AutoVideo AI — V12 STORY STUDIO

Prompt → Viral Story → Master Character → Character/World Bible → Shot-by-shot visuals → Motion → Voice → Music → VAIBHAV → MP4.

## Core idea
V12 is designed for recurring AI characters and short-form story channels. It creates an immutable Character DNA and World DNA, then injects those into every shot prompt. An optional uploaded Master Character image can be used as the visual reference for the whole project.

## Providers
- Pollinations image/story provider (API key entered at runtime)
- Hugging Face image/story/motion provider (API key entered at runtime)
- Optional Runway image-to-video provider
- Local FFmpeg cinematic fallback

## Deploy
Use `app.py` as the Streamlit main file. Keep `packages.txt` and `requirements.txt` in the repo.
